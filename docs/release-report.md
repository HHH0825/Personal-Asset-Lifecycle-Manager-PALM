## 已知限制

- 本版只供本机使用，不提供公网部署、邮件找回密码、独立 EXE、照片批量导出或数据导入。
- 当前执行环境的 npm 仓库访问间歇超时，未能现场完成 `npm install`。浏览器测试使用本机已有的同版本 Playwright 运行并通过；`package.json` 固定了开发依赖版本。运行 PALM 不需要 npm。
- Edge 页面已按截图人工复核；交互流程由浏览器自动化完成，未另做人工逐项点击演示。

依据全部自动化回归与隔离副本验证，核心流程无阻断，定版为 **v1.0.0**。
