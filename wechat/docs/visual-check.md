# 物物记：旧纸收藏册与操作纸券验收记录

## 本轮变化

燕麦纸底、鼠尾草格纹、陶粉纸片与奶咖胶带替换上一轮的柔光渐变、星星与鲜亮矩形。新增、收藏纸条和三个章节标题使用原创 SVG 同步导出的透明 PNG；文字与编号仍为原生组件，新增仍为原生按钮。本次追加收藏册登录入场券、归档保存票据和猫爪收藏册 Logo：本地文案为“登录体验”，正式文案为“微信登录”，保存仍明确写“保存物品”。两个入口保留原生按钮及加载禁用行为；首页 Logo 显示为 32×32px，失败回退“物”字。卡片、费用栏和输入框保持纯色，六张小猫贴纸沿用原素材。

所有修改位于 `wechat/`，没有修改后端接口、数据库、正常登录配置或原单机网页版。页面内容最大宽度、自然滚动、安全区域与短屏适配继续沿用。
