# 物物记：导师演示与验收清单

1. 在 `wechat/` 目录运行 `.\.venv\Scripts\python.exe backend\dev.py`，看到“本地模拟登录已开启”后保持终端打开。用微信开发者工具导入 `miniprogram/`，点击“登录体验”，展示“物品、发现、我的”三个入口。正式体验版改用真实微信登录配置。
2. 录入相机：类型“数码”，填写购买价、购买日期、保修日期并上传照片。进入详情核对持有天数、购买价/天和净成本/天。
3. 录入一条维修，观察维修费用和净成本变化。使用记录已退役；若账号已有旧数据，可展开详情底部“历史使用记录”，说明仅供查看、不能新增或修改。
4. 记录出售和回收金额，查看已处置状态；编辑或删除错误记录，观察费用重新计算。
5. 打开“发现”，查看保修、手动闲置、费用发现等规则卡片，点击涉及的物品跳转详情。未填写使用记录不会产生闲置推断。
6. 删除相机，到“我的 → 回收站”恢复；再次删除并永久删除，说明 30 天保留及记录、照片一并清理。
7. 用另一微信账号登录，确认看不到前一账号的物品、照片、统计和回收站；退出后原账号重新登录，数据仍在。

本机模拟器可覆盖页面和 API 联调；最终 Android、iPhone 真机及体验版上传需要真实 AppID、HTTPS 服务和体验成员。当前未提供这些外部资源时，该部分验收须由部署者完成。

## 收藏册功能补充演示

1. 物品页切换“档案／照片墙”，用分类、状态与搜索组合筛选，再选择费用排序；“清除筛选”保留视图和排序。
2. 进入物品详情，检查“编辑物品”和“更多操作”；展开基本资料、维修与处置、纪念，再返回清单核对原筛选与滚动位置。历史使用区域独立收起。
3. 详情设置日均目标，说明只按购买价均摊；修改和取消后重新核对。购买当天仍显示“暂无”，已处置目标只读。
4. 打开“我的 → 陪伴纪念册”，选择一枚日期章进入相应物品；纪念按购买日期自动计算。
5. 在“发现”的月度画页预览打开“收藏小报”，切换历史月份，再回到当前月；核对购入件数、三项费用、收支差额、同尺度费用横条、最高购入物品摘要与当月纪念。说明收支差额不同于累计净成本，零总支出不显示占比；旧使用记录不计月度活动。
6. 点“预览画页”，查看原生 Canvas 生成的 PNG：月份字样、插画与账目保持相同风格，图片高度随内容调整，最多三件购入物品与三条纪念，超出部分注明数量。手机上点“保存到相册”，由用户处理权限；拒绝后应保留页面并可重试。
7. 更正历史记录，或将物品移入回收站后恢复，重新进入小报，说明历史结果会随当前保存的数据更新。

正常后端仍为 5001；界面验收使用 5002 独立虚构账号，不把测试物品录入自己的日常账号。

## 草稿与历史数据定向检查

1. 新增时填写名称并选取照片，返回清单后再次进入，继续草稿并核对照片；确认重新填写与主动丢弃都需要确认。
2. 创建物品后模拟照片上传失败，确认物品已经存在，后续进入编辑重传照片，不会恢复成待创建草稿。
3. 旧使用记录日期早于新的购买日期或晚于新的处置日期时，旧记录保持可读且不阻止编辑；维修与处置的有效日期关系仍需要满足。
4. 需要检查停用 API 时，在独立测试数据中调用旧使用写入入口；所属账号得到 410，无权限账号得到 404，未登录得到 401。不要通过正常账号写入验证数据。
5. 同时检查空月份、零价物品、回收超过本月支出与并列最高购入；月份切换、读取失败或账号切换后不能预览上一页的旧图片。
