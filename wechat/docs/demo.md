# 物物记：导师演示与验收清单

1. 在 `wechat/` 目录运行 `.\.venv\Scripts\python.exe backend\dev.py`，看到“本地模拟登录已开启”后保持终端打开。用微信开发者工具导入 `miniprogram/`，点击“本地体验，开始记录”，展示“物品、发现、我的”三个入口。正式体验版改用真实微信登录配置。
2. 录入相机：类型“数码”，填写购买价、购买日期、保修日期并上传照片。进入详情核对持有天数、购买价/天和净成本/天。
3. 点“今天用过”，再次点击，确认同一天不重复；补录一条历史使用和一条维修，观察维修费用和净成本变化。
4. 记录出售和回收金额，查看已处置状态；编辑或删除错误记录，观察费用重新计算。
5. 打开“发现”，查看保修、使用复盘、费用发现等规则卡片，点击涉及的物品跳转详情。
6. 删除相机，到“我的 → 回收站”恢复；再次删除并永久删除，说明 30 天保留及记录、照片一并清理。
7. 用另一微信账号登录，确认看不到前一账号的物品、照片、统计和回收站；退出后原账号重新登录，数据仍在。

本机模拟器可覆盖页面和 API 联调；最终 Android、iPhone 真机及体验版上传需要真实 AppID、HTTPS 服务和体验成员。当前未提供这些外部资源时，该部分验收须由部署者完成。
