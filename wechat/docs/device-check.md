# 物物记：Android 与 iPhone 照片验收

目前只有本地后端，尚未完成真机验收。两台手机均需使用真实微信登录与可访问的 HTTPS 测试后端。本机 `127.0.0.1:5001` 是电脑的回环地址，不能直接作为手机体验版服务。

## 准备独立测试版本

1. 按 [部署说明](deployment.md) 部署独立测试后端与测试数据库，准备 HTTPS 域名、证书、AppID 和服务端 AppSecret。购买服务前由项目负责人确认预算。
2. 将 `miniprogram/` 复制到独立测试目录。参考 [真机配置样例](../deploy/miniprogram.config.example.js) 填写该副本的 `config.js`，设置真实 HTTPS 地址及 `DEV_LOGIN: false`；在副本 `project.config.json` 填写对应 AppID。正常开发项目继续连接 5001。
3. 微信后台配置 request、uploadFile、downloadFile 合法域名，并核对当前平台的隐私声明、体验成员与上传要求。AppSecret 只放在服务端环境配置，不放前端或 GitHub。配置样例不能直接登录。
4. 完整编译测试副本，上传后由体验成员分别在 Android、iPhone 打开。权限请求由持机人手动处理。本地调试入口保持只接受本机请求，不为真机放开模拟身份。
5. 先验证真实登录、`/healthz`、一张照片上传及下载。记录版本或提交号，之后再进行下表操作。

微信能力可核对 [官方 API 定义](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)，平台后台的要求以操作当天为准。

## 请求与首次显示记录

固定同一组至少六件带照片物品：首次打开清单，滚动经过全部照片；进入一件详情再返回，重复同一路径。记录照片请求数与响应体字节数、首次照片出现和清晰照片替换的体感或录屏时间。清单请求 `size=thumb`，详情与编辑请求 `size=full`；缓存有效的返回不应再次下载同版本缩略图。

弱网下先看占位与布局，再看错误重试。不要将后端响应耗时或电脑缓存回放耗时当作手机显示耗时。样例仅代表这组图片；不同图片、网络和手机的收益会不同。
